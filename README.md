A deterministic Node program that writes one line — an alien tourist's review
of planet Earth — to `/output/entry.txt`.

> Earth: the locals invented a machine to wake them up, then a button to ignore it for nine more minutes. Four stars, would snooze again.

## Run

```sh
node main.ts
cat /output/entry.txt
```

No dependencies, no network, no randomness: every run writes the same
135-character line.
